Feature Notes

This page documents the calculations used by the plain HTML text analyzer.

Back to Analyzer Login Sign Up

Core Counts

  • Words are matched from letters and numbers.
  • Characters are counted with spaces and without spaces.
  • Sentences count every period, exclamation mark, and question mark.
  • Paragraphs are counted from non-empty text blocks split by new lines.

Advanced Analysis

  • Keyword frequency uses a JavaScript object like a Python dictionary.
  • Common small stop words are skipped for clearer keyword results.
  • Reading time is calculated at 225 words per minute.
  • Case buttons convert all text instantly.

Cleaning Tools

  • Remove extra spaces can collapse repeated whitespace.
  • Remove punctuation can strip symbols from text.
  • Find and replace fields are ready for word substitutions.
  • Save Analysis is prepared for storing text and statistics.

Regex Practice

  • Email detection can use Python's re module.
  • URL detection can search for web address patterns.
  • Custom pattern input allows focused text scans.
  • History pages can show previous pattern results.

Readability Formula

The analyzer uses a Flesch-style score:

206.835 - 1.015 * (words / sentences) - 84.6 * (syllables / words)
